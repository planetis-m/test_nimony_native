# tnative

Throwaway project that runs the `nimony-native-release` workflow and installers on real GitHub runners.

Install on Linux and macOS:

    curl -fsSL https://github.com/planetis-m/test_native_ci/releases/latest/download/install.sh | sh

Install on Windows:

    irm https://github.com/planetis-m/test_native_ci/releases/latest/download/install.ps1 | iex

Targets: linux/amd64, linux/arm64, macos/arm64, windows/amd64.
